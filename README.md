# 冯铭谦的工作台

手机端个人工作台：待办、专注、课表、速记、记账、资料，一屏搞定。
纯静态站点，数据存在浏览器本机（localStorage），不联网、不上传。

- 线上地址：https://happydanm.github.io/workbench/
- 风格：柔和立体（同色底 + 一亮一暗双阴影），改配色只动 `tokens.css`
- 结构：`index.html` 页面、`styles.css` 样式、`app.js` 交互、`manifest.webmanifest` + `sw.js` + `icons/` 让浏览器能装成 App

## 手机上装成 App

用手机浏览器打开线上地址 → 菜单里选「安装应用」或「添加到主屏幕」。装好后是全屏、无地址栏，断网也能打开。

## 能用的功能

- 今日重点：进度环 + 自动挑出下一件没做完的事
- 待办：勾选、删除、添加、清空已完成
- 专注：25 分钟番茄钟
- 速记：输入自动保存
- 今天的课：三条课表，周几跟日期走
- 记账：支出/收入流水，今日合计
- 资料：常用链接收藏
